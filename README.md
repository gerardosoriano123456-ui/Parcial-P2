# Parcial-P2

Aplicación de escritorio en C# con Windows Forms que presenta ejercicios de programación básica y POO: variables, condicionales, ciclos, clases, herencia, polimorfismo, encapsulamiento e interfaces.

## Requisitos

- Windows
- .NET 10 SDK

## Ejecutar

Desde la carpeta del proyecto:

```powershell
dotnet run --project .\practicaparcial.csproj
```

En Visual Studio Code, abre la carpeta que contiene `practicaparcial.csproj`, instala la extension **C#** de Microsoft y pulsa `F5`. La configuracion del proyecto compila y arranca la aplicacion.

Para compilar una version de produccion:

```powershell
dotnet build .\practicaparcial.csproj --configuration Release
```

## Contenido

- Variables y tipos basicos
- Condicionales y bucles
- Clases y objetos
- Herencia y polimorfismo
- Encapsulamiento con una cuenta bancaria de ejemplo
- Interfaces y abstraccion
